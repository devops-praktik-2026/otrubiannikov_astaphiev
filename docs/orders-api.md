# API сервиса заказов

Сервис доступен локально по адресу `http://localhost:8002`. Все запросы и
ответы используют JSON.

## Модель заказа

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | integer | Уникальный номер заказа, назначается сервисом |
| `account_id` | integer | Номер клиента |
| `item` | string | Название товара |
| `quantity` | integer | Количество товара, не меньше `1` |

## `POST /orders`

Создаёт заказ для существующего клиента.

Тело запроса:

```json
{
  "account_id": 1,
  "item": "Кофемолка",
  "quantity": 2
}
```

Успешный ответ — `201 Created`:

```json
{
  "id": 42,
  "account_id": 1,
  "item": "Кофемолка",
  "quantity": 2
}
```

Возможные ошибки:

- `404 Not Found` — клиент с указанным `account_id` не найден;
- `422 Unprocessable Entity` — отсутствует обязательное поле, передано поле
  неверного типа или `quantity` меньше `1`.

## `GET /orders/{id}`

Возвращает заказ по его номеру. Параметр пути `id` — положительное целое
число.

Пример запроса:

```http
GET /orders/42
```

Успешный ответ — `200 OK`:

```json
{
  "id": 42,
  "account_id": 1,
  "item": "Кофемолка",
  "quantity": 2
}
```

Возможные ошибки:

- `404 Not Found` — заказ с указанным номером не найден;
- `422 Unprocessable Entity` — `id` имеет неверный формат.

## `GET /orders?account_id={account_id}`

Возвращает заказы указанного клиента. Результат можно ограничить необязательным
параметром `limit` — положительным целым числом.

Пример запроса:

```http
GET /orders?account_id=1&limit=10
```

Успешный ответ — `200 OK`:

```json
[
  {
    "id": 42,
    "account_id": 1,
    "item": "Кофемолка",
    "quantity": 2
  }
]
```

Если у клиента нет заказов, сервис возвращает `200 OK` и пустой список `[]`.

Возможные ошибки:

- `422 Unprocessable Entity` — `account_id` не указан или имеет неверный
  формат либо `limit` меньше `1`.
